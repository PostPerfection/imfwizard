Features

Standards-compliant IMF package creation, from essence to validated delivery.

📦

AS-02 MXF Wrapping

Wrap JPEG 2000 codestreams and PCM audio into SMPTE 2067-5 compliant MXF track files with full metadata.

🎬

Image Encoding Pipeline

Accept supported video input and encode 12-bit JPEG 2000 through OpenJPEG. Incompatible App 2E dimensions fail before packaging.

🎞️

ffmpeg Transcode

Transcode video files via ffmpeg (pick the output codec, e.g. libx264 or ProRes).

📋

IMF Packaging

Write complete CPL, PKL, and ASSETMAP references with base64 hashes, identifying App 2E.

📝

TTML Subtitles

Package TTML / IMSC subtitles as AS-02 timed text MXF. Convert SRT to TTML.

🎥

Dolby Vision & HDR10+

Inject Dolby Vision RPU and HDR10+ dynamic metadata for HDR IMF packaging.

🎨

ACES Colour Pipeline

IDT → RRT → ODT conversion via ctlrender (with an ffmpeg fallback).

📊

Loudness Analysis

EBU R128 integrated and true-peak measurement (measurement only, no normalization).

✅

Structural Validation

Validate IMPs via the DCP Doctor engine (ASSETMAP/PKL/hash checks) plus CPL/PKL signature verification, optional XSD schema checks, and optional Netflix Photon (--photon, needs a JRE + jar).

⚡

Delivery Presets

One-click configuration for Netflix, Disney+, Amazon, Apple TV+, Cinema 2K/4K, Broadcast, Archival.

🔐

Hash & Signing

SHA-1 hash computation for all assets with optional XML-DSIG signing for secure delivery.

🖥️

Desktop GUI

Tauri 2 desktop app with dark theme. Timeline scrubber with timecode display, mpv preview player, subtitle burn-in, file import, keyboard shortcuts, and desktop notifications.

🎞️

ProRes Encode

Encode a video or image sequence to a ProRes .mov master (proxy/lt/standard/hq/xq).

🔤

Subtitle Burn-In

Render SRT/TTML subtitles into video frames via ffmpeg.

🎬

IMF → DCP

Convert IMF packages to Digital Cinema Packages for theatrical exhibition.

📊

Bitrate Analytics

Per-second bitrate charts, histograms, and statistics. JSON export for dashboards.

🚀

Batch Delivery

Create IMPs for Netflix + Disney+ + Amazon + Apple TV+ in a single command.

🌐

REST API Server

HTTP interface for automated workflows. Endpoints for create, validate, encode, transcode, and job management.

✂️

EDL / FCP XML Import

Parse CMX 3600 EDL and Final Cut Pro XML timelines into edit events for CPL assembly.

🔍

Frame Comparison

PSNR/SSIM comparison between two video files or IMPs, plus optional VMAF (--vmaf, needs an ffmpeg with libvmaf). Per-frame metrics with JSON export.

🎵

Dolby Atmos ADM Import

Import ADM Broadcast Wave Format files and wrap the PCM essence to MXF (not a Dolby IAB bitstream).

🏷️

MCA Label Generation

SMPTE ST 377-4 Multi-Channel Audio labeling with 5.1, 7.1, and stereo soundfield presets.

🗣️

Audio Description

Mix AD narration track with main audio using intelligent ducking for accessibility compliance.

🎨

3D LUT Application

Apply .cube LUT files to image sequences for color grading in the IMF pipeline.

🌈

ACES Color Pipeline

Full IDT→RRT→ODT pipeline via ctlrender with automatic ffmpeg colorspace fallback.

⏱️

A/V Sync Detection

Compare the first audio and video presentation timestamps to detect drift.

✅

Platform Compliance

Validate against Netflix, Disney+, Amazon, Apple, Cinema 2K/4K, and Broadcast delivery specs.

📊

QC Report

Generate a QC report in text, JSON, or HTML with package info.

📝

CPL Annotation

Add revision notes, author metadata, and version tracking to CPL XML documents.

🧩

Partial Version

Copy the files a given CPL UUID references into a new IMP.

🎬

Slate Generation

Prepend a black text slate as image frames.

⏩

Video Retiming

Change a video file's frame rate via ffmpeg.

📺

SDI Preview (Blackmagic DeckLink)

Play J2K frames via mpv DeckLink output.

⌨️

Shell Tab Completion

Generate completion scripts for bash, zsh, and fish. Auto-complete all subcommands and flags.

📄

XSD Schema Validation

Validate CPL, PKL, and AssetMap XML against SMPTE ST 2067 XSD schemas via xmllint.

🩺

Dependency Doctor

Built-in doctor subcommand checks all external tool dependencies with version detection and JSON output for CI/CD.

Installation

Build from source in minutes. Requires Rust 1.85+.

Prerequisites

RequiredRust toolchain (1.85+)
RequiredCMake (for asdcplib FFI build)
RequiredOpenSSL, Xerces-C (for asdcplib)
Runtimeffmpeg / ffprobe (transcode, loudness)
Built inOpenJPEG (J2K encoding)
Optionaldovi_tool (Dolby Vision RPU injection)
Optionalctlrender (ACES CTL transforms)
OptionalNode.js 24 + pnpm 11 + Rust (GUI build)
Optionalxmllint / libxml2-utils (XSD schema validation)
Optionalmpv (GUI/SDI preview)
Optionalffmpeg with libvmaf (compare --vmaf)
OptionalJRE + Photon jar (validate --photon)
Optionalascp (Aspera FASP high-speed transfer)

Run imfwizard doctor to check which tools are installed.

1

Clone

git clone --recurse-submodules https://github.com/PostPerfection/imfwizard.git

2

Build CLI

cd imfwizard/rust && cargo build --release

3

Run Tests

cargo test in the rust directory to verify everything works.

4

GUI (Optional)

cd gui && pnpm install && pnpm tauri dev

Quick Start

Create your first IMP in minutes.

# Create IMP from J2K + WAV
$ ./imfwizard create \
    --title "My Feature Film" \
    --video /path/to/j2k_frames/ \
    --audio /path/to/audio.wav \
    --output /path/to/output_imp/

# Create IMP with subtitles and HDR (auto-encodes DPX to J2K)
$ ./imfwizard create \
    --title "My HDR Film" \
    --video /path/to/dpx_frames/ \
    --subtitle /path/to/subs.ttml \
    --color-space bt2020-pq \
    --output /path/to/output/

# List delivery presets
$ ./imfwizard profiles

# Measure loudness
$ ./imfwizard loudness /path/to/audio.wav

# Validate an IMP (add --xsd for schema checks)
$ ./imfwizard validate /path/to/imp/

# Scale video to target resolution (2K/4K scope/flat/full)
$ ./imfwizard target-convert -i video.mov -o video_4k.mov -t 4k-scope

# Burn subtitles into video
$ ./imfwizard burn-in -i video.mp4 -s subs.srt -o burned.mp4

# Check external tool dependencies
$ ./imfwizard doctor

# JSON output for CI/CD
$ ./imfwizard doctor --json
